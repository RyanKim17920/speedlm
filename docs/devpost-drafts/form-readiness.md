# Devpost form-readiness map

Checked September 1, 2026. Devpost's published submission flow uses the
following standard fields. Organizer-specific Additional Details are visible
only inside a registered, authenticated draft and were not exposed to this
workspace's logged-out reader.

## Standard fields

| Step | Field | SpeedLM answer/source | State |
| --- | --- | --- | --- |
| Team | Teammates | Entrant supplies solo/team roster and Devpost accounts | owner-only |
| Basics | Project name | `SpeedLM — Faster Local LLMs From Idle GPU Time` unless the event packet provides a more audience-specific title | ready |
| Basics | Project tagline, maximum 140 characters | `Automatically speeds up local LLMs with idle GPU time.` | ready (54 characters) |
| Basics | Thumbnail | `docs/assets/devpost/06-local-inference-gap.png` | ready locally; upload pending |
| Project | Project story | Event packet's `Project story`, `Full story`, `Detailed description`, or `Written story` section | ready |
| Project | Built With, maximum 25 tags | Event packet's `Built With` section | ready |
| Project | Try It Out | `https://github.com/RyanKim17920/speedlm` | ready and public |
| Project | Image gallery | Use the event packet's exact asset plan and captions from `assets.md` | ready locally; upload pending |
| Project | Video demo | Use 59 s, 119 s, or 150 s according to `assets.md`; a local MP4 is not a hosted URL | upload/hosting varies |
| Additional Details | Organizer questions | Exact prompt, required marker, options, and limit must be copied from the authenticated draft | blocked on visible form |
| Submit | Rules and terms | Entrant personally reviews and accepts | owner-only |

The standard thumbnail accepts JPG, PNG, or GIF up to 5 MB; Devpost recommends
a 3:2 image. The current story-first PNG is 1920×1080 and below the size limit,
but Devpost may crop it in card views. A custom file-upload question, when an
organizer enables one, can have different accepted formats and a 35 MB limit;
do not assume that it accepts a PNG when the Image Gallery already does.

## What to capture from each authenticated form

For each Additional Details page, record:

1. The exact question text and whether it is required.
2. Every selectable option and whether multiple selections are allowed.
3. Character or word limit.
4. Accepted upload types and maximum size.
5. Any project-timing, prior-entry, category, country, license, AI-use, or
   sponsor-technology attestation.

Screenshots or copied page text are sufficient; account cookies and private
tokens are neither needed nor appropriate.
