# Owner inputs needed to finish the live Devpost forms

Project copy is already drafted in each event packet. These fields require the
entrant's own facts or attestation and must not be inferred from Git history or
an account profile.

## Identity and eligibility

- Full name exactly as it should appear on the submission
- Country and region of residence
- School or institution, program/level, and expected graduation year if asked
- Confirmation that age 18 is the legal age of majority in the entrant's
  jurisdiction
- Solo submission or team; for every member: real name, Devpost account, and
  project role

## Project history

- Actual date material work on SpeedLM began, including work before the first
  July 25, 2026 repository commit
- Every previous hackathon submission of SpeedLM or a substantially similar
  project, including event and submission date
- Whether SpeedLM has been commercialized, entered for another prize, or built
  under an employer/school agreement
- Which material features were completed inside VoltHacks' May 22–September 5
  window
- For GIBC only: whether all material work falls inside July 11–September 21
  and whether any prior entry triggers its substantially-same-project rule

## Media delivery

- Public/unlisted YouTube, Vimeo, or Youku URL for the 150-second GIBC video
- Public YouTube or Vimeo URL for the 150-second Arbiter video when submissions
  open October 20
- Decide whether VoltHacks will use the 119-second video or a presentation
- Upload the screenshots listed in each event packet; a local path is not a
  judge-facing attachment

## Personal attestations

The entrant must personally review and accept eligibility, originality,
rights, privacy, event-rules, and Devpost terms checkboxes. A saved draft is not
evidence that those statements are true.

## Authenticated-form limitation

This workspace does not have access to the authenticated in-app browser DOM.
If an event displays organizer-only custom questions that are absent from its
public rules, copy their text or attach screenshots. Add each exact prompt,
required marker, option list, and character limit to the matching event packet
before final submission.
